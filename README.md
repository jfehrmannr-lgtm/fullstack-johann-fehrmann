# Psychologist Pablo Martinez - Landing Page

> Proyecto de landing page para el psicólogo Pablo Martinez, desarrollado con **React 19**, **Vite**, **TailwindCSS** y **Ant Design 5**.

---

## 📝 Descripción

Esta es una landing page profesional y responsiva creada para presentar los servicios del psicólogo Pablo Martinez. La aplicación está construida utilizando modernas herramientas de frontend:

- **React 19** para la interfaz de usuario.
- **Vite** como bundler y entorno de desarrollo.
- **TailwindCSS** para estilos utilitarios rápidos y consistentes.
- **Ant Design 5** para componentes UI avanzados y accesibles.

El proyecto está estructurado con TypeScript para garantizar tipado seguro y escalabilidad.

---
